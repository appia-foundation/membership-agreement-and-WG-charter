# Appia Membership Agreement Package

This repository contains the legal and governance documents that make up the Appia Foundation's Membership Agreement Package. Appia operates as a series project of Joint Development Foundation Projects, LLC ("JDF"), a Linux Foundation entity.

Anyone joining Appia — or forming a new Working Group under it — executes some or all of the documents described below. This README explains what each document does and how they relate to one another, so members and prospective members know what they're signing before they sign it.

## What's in the Package

The Membership Agreement Package is made up of four documents. Not every document applies to every party — see [Which Documents You Need](#which-documents-you-need) below.

| Document | Purpose |
|---|---|
| [Membership Agreement](#1-membership-agreement) | Signed by every Member to join Appia |
| [Project Charter](#2-project-charter) | Establishes Appia's governance and legal structure |
| [Working Group Charter](#3-working-group-charter) | Establishes governance, scope, and IP terms for a specific Working Group |
| [Project Sponsorship Agreement](#4-project-sponsorship-agreement) | Sets fee terms for Members providing financial support |

### 1. Membership Agreement

The document every Member signs to formally join Appia. It's short by design — most of the substance lives in the Project Charter, which it incorporates by reference.

Key terms:
- **Membership Level** — each Member selects one of three levels: Steering Member, General Member, or Contributor Member.
- **Order of Precedence** — if documents conflict, they're resolved in this order: Membership Agreement → Project Charter → Working Group Charter → Steering Committee-adopted policies.
- **Effective term** — runs from countersignature until withdrawal or termination as defined in the Project Charter.

### 2. Project Charter

The foundational governance document for Appia as a whole. It establishes:

- **Project description and scope** — Appia develops a practical, internationally aligned framework of AI conformity specifications, modularized across roles in the AI value chain (providers, integrators, component suppliers, deployers).
- **Membership levels and rights**:
  - *Steering Member* — participates in Working Groups and the Steering Committee.
  - *General Member* — participates in Working Groups only.
  - *Contributor Member* — participates in designated Working Group(s) only; not eligible to vote on Supermajority decisions.
- **Steering Committee** — the body governing the Project, including approval of Final Deliverables, chaired by a designated Chairperson.
- **Decision-making** — Consensus by default, falling back to a Supermajority Vote (75% of Active Voting Members) when Consensus isn't reached.
- **Openness and due process** — any party with a direct, material interest may participate; the Project follows consensus-based due process (openness, balance, notice, fair consideration of objections).
- **Withdrawal, termination, and IP disclaimers** — including how commitments survive a Member's exit and the "AS IS" disclaimers that apply to all deliverables.
- **Definitions** — a full glossary (Active Voting Member, Consensus, Supermajority Vote, Working Group, etc.) that governs interpretation across the whole package.

### 3. Working Group Charter

Each Working Group operating under Appia has its own charter, executed separately from the Project Charter. It sets:

- **Deliverable type(s)** — Specifications, Source Code, and/or Datasets.
- **Governance mode** — either *Community Specification* mode (repository-based, open-source-style workflow) or *Traditional* mode (standards-body-style governance, detailed in Appendix A of the charter).
- **Scope** — the specific technical objective of that Working Group.
- **IP terms** — copyright licensing (e.g., Copyright Grant to Project) and patent licensing (e.g., RAND Royalty-Free, International Mode, Open Web Foundation, or No Patent License), selected per Working Group.

Only Members who have Joined a given Working Group are bound by — and permitted to participate under — that Working Group's Charter.

### 4. Project Sponsorship Agreement

Applies only to Members providing financial support to Appia. This is a Directed Fund Participation Agreement executed directly with The Linux Foundation (not with Appia or JDF), and requires separate Linux Foundation membership. It sets:

- **Participation Fees by level** — Steering Member ($50,000), General Member ($25,000), Contributor Member ($1,000).
- **Billing and renewal terms** — annual, non-refundable, calendar-year renewal cycle.
- **Termination conditions** and how fees are applied (including the Linux Foundation's G&A fee).

## Which Documents You Need

| If you are... | You execute... |
|---|---|
| Joining Appia at any membership level | Membership Agreement + Project Charter (by reference) |
| Joining a specific Working Group | The relevant Working Group Charter, in addition to the above |
| Providing financial sponsorship | The Project Sponsorship Agreement, in addition to the above |
| Contributing without becoming a Member | The Non-Member Agreement (Appendix C to the Project Charter) |

## How to Join

1. Review the full Membership Agreement Package with your organization's stakeholders.
2. Identify your organization's authorized signatory and any other key contacts.
3. Confirm which membership level you're joining at (Steering, General, or Contributor).
4. Follow the execution instructions on the Appia website.

Each Member executes the same set of documents — redlines are not accepted. Questions about the process can be directed to the Project Chairperson or Appia's membership operations team.

## Precedence and Conflicts

If any documents in this package conflict, they control in the following order (highest to lowest):

1. Membership Agreement
2. Project Charter
3. Working Group Charter
4. Steering Committee-adopted policies and procedures
